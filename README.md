
# How to overcome the browser height limitation in virtual scrolling

This sample demonstrates the possible solutions to overcome the browser height limitation in the virtual scrolling feature of the Grid. It provides guidance for scenarios where large datasets are displayed and default browser height restrictions can affect smooth scrolling behavior, especially when working with extensive records in real-time applications. The goal of this sample is to show practical approaches that ensure consistent performance and usability.

## How to run the project

* Checkout this project to a location in your disk.
* Open the solution file using Visual Studio.
* Restore the NuGet packages by rebuilding the solution to make sure all required dependencies are available.
* Run the project to launch the sample and observe how the virtual scrolling enhancements help in bypassing the browser height limits during data rendering.
